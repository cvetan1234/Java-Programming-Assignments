# Concurrent Prime Numbers Checker
Finds all prime numbers up to a user-defined limit, using user-defined number of threads. It is an extended version where once discovered numbers are saved to a file and then reused.

### Getting Started:
- To start the project, simply open the project in IntelliJ IDEA and run the Main method (Path: aufgabe1/main/java/Main) using the run functionality. No additional setup steps are required.
